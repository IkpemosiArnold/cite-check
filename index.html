Cite Check

A link is not proof. This checks, in plain code, that each quote in an AI answer is really in its source.

Result

Sample answer, written for this demo. Two errors were planted on purpose.

    Try your own

    Paste an answer and its sources in this plain format. Separate blocks with a line of three dashes.

    CLAIM: what the answer says
SOURCE: the source ID
QUOTE: words copied from the source
---
ID: the source ID
TITLE: page name
URL: https://example.gov/page
TEXT: the full source text
